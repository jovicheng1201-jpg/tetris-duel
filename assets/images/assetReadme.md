# Image Assets

The built-in `image_gen` tool was not available in this task, and the CLI fallback was not enabled because it requires an API key and explicit CLI confirmation. These files are therefore deterministic SVG placeholders that can be used immediately by the Web game and PDF pipeline.

Files:

- `cover.svg`: cover composition with Milo, Puff, forest, and rainbow space.
- `milo.svg`: Milo character reference.
- `puff.svg`: Puff character reference.
- `scene01_discovery.svg`: Milo finds Puff in the oak tree.
- `scene02_wind.svg`: Windy Hill attempt and berry bush.
- `scene03_mountain.svg`: Sunbeam Mountain attempt.
- `scene04_dryforest.svg`: thirsty forest before the rain.
- `scene05_firstdrop.svg`: Puff creates the first raindrop.
- `scene06_rainbow.svg`: rainbow after the gentle rain.
- `scene07_cloudfriends.svg`: Puff meets the friendly large clouds.
- `scene08_welcome.svg`: ending welcome scene for a new cloud.

The intended final visual direction, if raster generation becomes available, is the prompt set in `material.md`: warm children’s picture-book watercolor and colored-pencil illustration, consistent orange-red Milo with green scarf and brown backpack, and round white Puff with pale-blue shadows and no limbs.
